# 静态像素画产品方向

## 用户确定的边界
- Aseprite Plus 面向静态像素画编辑，用户只操作图层，不操作帧。
- 保留旧动画代码，通过隐藏界面入口取消动画工作流；不删除旧实现。
- 所有新功能不提供帧动画、跨帧能力；底层调用仍需满足 Aseprite 原有文档结构。
- 仿制图章采用像素笔刷，不提供 PS 式软边硬度和独立流量。
- 取样交互为按一下快捷键，再点击画布位置；不要求按住 Alt。
- 图章使用时，画面需明确标记取样位置。

## 当前实施状态
已实现静态图层界面和原生像素仿制图章。已通过编译与图章局部自动回归；GUI、视觉和真实绘图手感仍由用户验收。

## 界面实施注意
- `src/app/ui/timeline/` 同时承担图层列表和帧时间轴，不能通过隐藏整个 Timeline 实现静态模式。需要保留图层管理并隐藏帧网格、标签、播放及洋葱皮控件。
- 动画入口还包括帧菜单、状态栏帧号/新增帧、预览播放、右侧时间轴入口和快捷键。仅隐藏底部帧网格不足以取消动画工作流。
- 禁用的是界面层动画操作入口；旧命令与文件格式实现继续保留。Lua/旧插件的动画能力不承诺移除。
- 底层文档仍有 frame/Cel 数据结构，不为了静态界面重写文件格式。

## 数据范围
用户明确不要求旧数据或动画工程兼容。UI 编辑器固定工作帧为内部第 0 帧；不删除上游文件格式/脚本数据结构，也不设计旧工程迁移策略。
README 开头说明无帧动画编辑能力，并要求使用者先备份工程。

## 当前界面与命令边界
- Timeline 使用静态分支渲染/命中图层列表，隐藏帧网格、播放控件、帧标签、连续帧图标、洋葱皮和时间轴配置按钮；组折叠继续可用。
- 状态栏隐藏帧号和新增帧，预览隐藏播放按钮；帧菜单、动画命令及导入/导出精灵表入口隐藏。
- 菜单/快捷键分发阻止动画命令，动画默认/用户快捷键不载入；编辑器固定帧 0 并不播放动画。
- UI 打开图片时不导入动画序列、不显示序列时长弹窗；上游批处理加载能力保留。
- 图层按钮沿用内部 Timeline 命令 ID，界面文案为 Layers；保留图层显隐、锁定、选择、分组和排序。
