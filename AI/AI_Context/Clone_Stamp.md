# 像素仿制图章

## 使用与范围
- 右侧原生 `clone_stamp` 工具；硬边圆形/方形/线形笔刷、尺寸、不透明度和取样范围。
- 默认 `Y` 调用 `CloneStampSource` 命令进入一次性取样状态，按键时的笔刷位置作为初始目标点，显示绿色 `+`；从绿点到鼠标选点位置持续显示虚线。取样光标为十字，不使用单像素方框；选 source 时不吸附网格。左键确认后 source 显示红色 `+`，并立即用 `source − Y 目标点` 确定复制偏移。Y 目标点沿用目标笔刷的网格吸附设置。
- 确认时先显示所选红绿点对；随后绿点跟随目标笔刷，红点按实际取样偏移移动。两点间持续保留带黑色描边的白色虚线，鼠标离开编辑器后保留最后点对和连线；非 Skia 后端回退实线。落笔期间使用绘图管线处理后的实际源/目标坐标。
- 绿色目标点与红色 source 点均显示同色笔刷外框，复用原生橡皮笔刷边界，随当前笔刷尺寸、形状和角度变化。按 Y 选点期间，绿色外框固定在 A 点，红色候选外框跟随选点鼠标；确认后两边外框跟随对应加号。外框带黑色描边，不额外叠加默认黑白笔刷轮廓；改变笔刷时立即刷新。
- 顶部取样按钮在鼠标不位于画布时不设置 Y 目标点，沿用首次落笔确定目标点的方式。Esc 取消等待取样，保留上次确认的源点和偏移，输入框沿用原生快捷键保护。
- 标记、连线和目标笔刷轮廓只在编辑器显示，不写入图片或导出结果。
- 当前文档、普通图像层和 Tilemap 层；支持 RGB/灰度/索引色。参考层不作为图章源/目标；不提供软边、流量、跨文档/跨帧、源旋转缩放、镜像和笔刷动态。
- 源图层在点击取样时确定，切换目标层不会替换源图层；可写入空的可编辑目标图层。
- 取样范围：取样图层、取样图层及以下的可见层、所有可见层。合成取样排除参考层、洋葱皮、网格、选区线和编辑器覆盖标记。
- 图章始终保留已确认的相对坐标：`取样点 = 当前笔刷点 + (B − A)`；A 为 Y 时的绿色目标点，B 为左键选择的红色 source 点。偏移跨笔画保留，直到重新取样；没有每笔重置源点的对齐开关。例如 B 在 A 左侧 10 像素，则所有后续绘制都读取当前笔刷左侧 10 像素处的源像素。
- 每笔一个绘图事务，支持撤销/重做和取消；目标选区/图层锁定沿用原生绘图规则。
- 透明源及越界源跳过；100% 不透明度通常直接保留索引；背景层的保留索引写入透明目标层时映射为不透明索引。部分不透明度映射回现有调色板，不扩充调色板。

## Tilemap
- 取样栅格化为 Sprite 像素，包含 Tile 翻转和 Cel 位置；支持 Tilemap 与普通层之间互相取样、绘制，取样范围设置照常生效。
- 图章始终使用像素模式与像素笔刷轮廓，即使颜色栏当前为整 Tile 模式；不更改用户的颜色栏模式，不把图章替换为整 Tile 画笔。
- 写回沿用 `ExpandCelCanvas` 原生 Tilemap 像素编辑与事务，保留图层类型，仍以 Tile ID 引用 Tileset。遵循当前 Tileset 编辑模式：Manual 修改共享 Tile，其他引用同步变化；Auto/Stack 按原生规则生成或匹配 Tile。Manual 不向空 Tile 创建新 Tile。
- 原生目标选区、不透明度、撤销/重做与取消有效。开启专注格子后可从格外取样，目标只写入专注格与用户选区的交集；Tilemap 目标在 Manual 下仅本次笔画改用 Auto，避免共享 Tile 修改传播到格外，不改颜色栏设置。详见 `Grid_Lock.md`。
- 带 `dual-grid-optimize-v1` 关联标记的 Tile 优化层遵守外部 Index 共享约定：专注笔画固定使用 Manual，同 Index 引用同步更新，详见 `Grid_Lock.md`。

## 实现入口
- `src/app/tools/clone_stamp.h/.cpp`：瞬时文档状态、取样快照、图章 Ink；`Doc::cloneStamp()` 持有状态，文档关闭时释放，不写入工程或撤销历史。
- `src/app/commands/cmd_clone_stamp_source.cpp`：按键/顶部按钮取样命令。
- `data/gui.xml`、`data/pref.xml`、`data/strings/en.ini`：工具/快捷键与参数注册。
- `src/app/ui/context_bar.cpp`：取样入口和范围控件，使用几何笔刷，禁用图像图案笔刷、镜像和动态控制。
- `src/app/ui/editor/standby_state.cpp`：源点击消费，普通绘图前校验图层类型。
- `src/app/ui/editor/editor.cpp`、`brush_preview.cpp`：红色 source / 绿色目标加号、取样与绘图虚线、同色源/目标笔刷轮廓和十字光标。
- `src/app/ui/skin/skin_theme.cpp`：按原生 UI 比例生成图章图标，不修改皮肤图集。
- `src/render/render.h/.cpp`：可选 layer filter，用于取样图层及以下的合成；默认渲染不受影响。

## 长期约束
- 必须在 `ExpandCelCanvas` 临时重定位目标 Cel 之前获取独立源快照，否则同层取样会错位。每笔重新取样，单笔源图不随目标写入变化。
- UI、脚本和预览的 ToolLoop 创建入口必须先将图章的 Site 设置为 Pixels，并在 Tilemap 格锁定时隔离 Manual 的共享 Tile，再处理 Tilemap Ink 替换和画布扩展；否则整 Tile 模式会丢失图章 Ink 或把 Tile ID 当像素。
- 不透明度从该笔开始前的目标源画布合成，不因一笔中重复覆盖而变成独立流量累积。
- Y 取样在确认 source 时初始化源/目标偏移；未提供 Y 目标点或需要重置偏移时，以笔画控制器处理后的首点初始化。红绿标记依据实际像素偏移更新。
- 源/目标坐标以 Sprite 坐标统一；写入时转换目标画布局部坐标，选区判断使用 Sprite 坐标。
- 图层删除以 ObjectId 查找失效，不保留裸源层指针；无效源要求重新取样。
- 标记只能由编辑器绘制，不能混入采样图、工程、导出或撤销数据。

## 验证入口
- `OLDKING_BUILD_CLONE_TESTS=ON` 生成 `build/bin/oldking_clone_tests`，通过脚本用 ToolLoopImpl/ToolLoopManager 执行真实绘图事务。
- 通过 `misc/test_clone_stamp.sh` 运行，使用独立 `ASEPRITE_USER_FOLDER`；不写入用户真实偏好目录。
- 可追加 `.aseprite` 路径作为 Tilemap 回归输入（单层 RGBA 测试素材）；只读原文件，隔离目录内验证图章、撤销/重做和另存重载。内置用例覆盖三种颜色格式、Tile 翻转/偏移、三种 Tileset 模式、跨层复制、选区、不透明度、取消与空 Cel。
- 最终图标、图层布局、取样光标和连续绘图手感由用户实际验收。
