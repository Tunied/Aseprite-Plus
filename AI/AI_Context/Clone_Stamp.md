# 像素仿制图章

## 使用与范围
- 右侧原生 `clone_stamp` 工具；硬边圆形/方形/线形笔刷、尺寸、不透明度、对齐开关。
- 默认 `Y` 调用 `CloneStampSource` 命令进入一次性取样状态，随后左键点击设置源点；顶部取样按钮提供同一入口。Esc 取消等待取样，输入框沿用原生快捷键保护。
- 源点十字和目标笔刷轮廓只在编辑器显示，不写入图片或导出结果。
- 当前文档、普通图像层；支持 RGB/灰度/索引色。Tilemap 和参考层不作为图章源/目标；不提供软边、流量、跨文档/跨帧、源旋转缩放、镜像和笔刷动态。
- 源图层在点击取样时确定，切换目标层不会替换源图层；可写入空的可编辑目标图层。
- 取样范围：取样图层、取样图层及以下的可见层、所有可见层。合成取样排除参考层、洋葱皮、网格、选区线和编辑器覆盖标记。
- 对齐开启跨笔保留源/目标偏移；关闭每笔从原始源点重新开始。改变对齐选项会重置偏移。
- 每笔一个绘图事务，支持撤销/重做和取消；目标选区/图层锁定沿用原生绘图规则。
- 透明源及越界源跳过；100% 不透明度通常直接保留索引；背景层的保留索引写入透明目标层时映射为不透明索引。部分不透明度映射回现有调色板，不扩充调色板。

## 实现入口
- `src/app/tools/clone_stamp.h/.cpp`：瞬时文档状态、取样快照、图章 Ink；`Doc::cloneStamp()` 持有状态，文档关闭时释放，不写入工程或撤销历史。
- `src/app/commands/cmd_clone_stamp_source.cpp`：按键/顶部按钮取样命令。
- `data/gui.xml`、`data/pref.xml`、`data/strings/en.ini`：工具/快捷键与参数注册。
- `src/app/ui/context_bar.cpp`：对齐和取样范围控件，使用几何笔刷，禁用图像图案笔刷、镜像和动态控制。
- `src/app/ui/editor/standby_state.cpp`：源点击消费，普通绘图前校验图层类型。
- `src/app/ui/editor/editor.cpp`、`brush_preview.cpp`：源点标记和硬边轮廓。
- `src/app/ui/skin/skin_theme.cpp`：按原生 UI 比例生成图章图标，不修改皮肤图集。
- `src/render/render.h/.cpp`：可选 layer filter，用于取样图层及以下的合成；默认渲染不受影响。

## 长期约束
- 必须在 `ExpandCelCanvas` 临时重定位目标 Cel 之前获取独立源快照，否则同层取样会错位。每笔重新取样，单笔源图不随目标写入变化。
- 不透明度从该笔开始前的目标源画布合成，不因一笔中重复覆盖而变成独立流量累积。
- 图章偏移在笔画控制器处理后的首点初始化，源标记依据实际像素偏移更新。
- 源/目标坐标以 Sprite 坐标统一；写入时转换目标画布局部坐标，选区判断使用 Sprite 坐标。
- 图层删除以 ObjectId 查找失效，不保留裸源层指针；无效源要求重新取样。
- 标记只能由编辑器绘制，不能混入采样图、工程、导出或撤销数据。

## 验证入口
- `OLDKING_BUILD_CLONE_TESTS=ON` 生成 `build/bin/oldking_clone_tests`，通过脚本用 ToolLoopImpl/ToolLoopManager 执行真实绘图事务。
- 通过 `misc/test_clone_stamp.sh` 运行，使用独立 `ASEPRITE_USER_FOLDER`；不写入用户真实偏好目录。
- 最终图标、图层布局、取样光标和连续绘图手感由用户实际验收。
