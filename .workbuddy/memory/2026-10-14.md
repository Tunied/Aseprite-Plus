## macOS 打包改造（验证过的硬事实）

- **实测**：CMake 的 macOS bundle 目录名和内容里的可执行文件都等于 `OUTPUT_NAME`，
  支持带空格；`MACOSX_BUNDLE_INFO_PLIST` 指定的 plist 会被当模板做 `${VAR}` 替换
  （`$(EXECUTABLE_NAME)` 不会被替换）。Ninja 会自动把路径里的空格写成 `Aseprite\ Plus`。
- 官方源码里 3 处硬编码 `bin/Aseprite.app` 是**笔误**：实际产物叫 `aseprite.app`，
  之前能跑通完全靠 APFS 大小写不敏感。已全部换成 `ASEPRITE_APP_BUNDLE_DIR` 变量。
- 品牌参数集中在根 `CMakeLists.txt`：`ASEPRITE_PLUS_NAME` / `ASEPRITE_PLUS_IDENTIFIER` /
  `ASEPRITE_PLUS_ICON`；`src/CMakeLists.txt` 负责 OUTPUT_NAME、DATA_OUTPUT_DIR、图标资源。
- 图标：`Aseprite-Plus Icon.png`(1254²) → `src/main/osx/AsepritePlus.png` →
  `misc/make_app_icon.sh` 生成 `AsepritePlus.icns`。换图标重跑该脚本即可。
- App 名称改为 `Aseprite Plus`，bundle id `studio.oldking.aseprite-plus`；
  程序内部关于窗口仍保留 Aseprite 标识（按 EULA 考量的有意保留）。
