## UI 默认字体替换为 Fusion Pixel Font
- 老板要求：用 TakWolf/fusion-pixel-font 替换 App 默认字体，不汉化界面，但界面中文
  （标题栏/状态栏/Home 最近文件）要正常显示且不再过大。
- 根因：中文走 `Aseprite → Unicode(size=14) → Arial Unicode` fallback 链，比例系统字体、偏大。
- 改动（纯数据，无 C++ 代码）：
  - `data/fonts/` 新增 `fusion-pixel-12px-proportional-zh_hans.ttf`、
    `fusion-pixel-10px-proportional-zh_hans.ttf`、`fusion-pixel-OFL.txt`
    （release 2026.09.25，OFL-1.1，GitHub 下载需走本机 Clash 7890 代理，
    沙箱透明代理 53395 下载大文件会断）。
  - `data/fonts/fonts.xml`：新增 `Fusion Pixel`（antialias=false, hinting=false,
    fallback→Unicode size=10）与 `Fusion Pixel Mini`（fallback size=8）。
  - `data/extensions/aseprite-theme/theme.xml` 与 `dark/theme.xml`：
    default→`Fusion Pixel size=12`，mini→`Fusion Pixel Mini size=10`。
- 机制备忘：主题字体槽位在 skin_theme.cpp loadXml，size 属性直接写在 theme.xml 的
  <font id=...> 上；fonts.xml 的 <font> 本身不解析 size；truetype 默认 size=10。
  pref.theme.font 非空时（用户在偏好里开过自定义字体）会覆盖主题字体。
- 验证：一键编译脚本增量编译并安装成功，包内字体/配置完整，ad-hoc 签名通过，
  --version 自检通过。GUI 效果由老板验收。
- 后续验证：fontTools 校验截图相关汉字零缺字；12px/10px 档位下 CJK advance 恰为
  12/10px（upm=设计px×10，整数倍缩放无半像素）；tabs.cpp:494 标签高度会按
  1.5*textHeight 自适应，主题写死尺寸不会被 12px 字体裁切。
  PIL 预览脚本注意：NEAREST 放大要整图画完再整体缩放，逐行贴图会重叠出错。
