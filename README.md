# Aseprite Plus

基于 [Aseprite](https://github.com/aseprite/aseprite) 的个人增强版本，面向 **macOS arm64 静态像素画**，与官方 App 可同时安装。不是 Igara Studio 官方发行版。

本文只介绍 Aseprite Plus 的独有特性，功能描述始终与当前实现同步。

## 更细腻的边缘自动滚动

按 **M** 使用选区工具，或使用绘图工具拖动到编辑器边缘时，画布默认以原版 **25%** 的速度自动滚动，减小越界时的跳动幅度。

在 **Edit → Preferences → Editor** 中：

- **Auto-scroll on editor edges**：开启或关闭边缘自动滚动。
- **Edge auto-scroll speed**：在 **1%–100%** 之间以 1% 为单位微调，默认 **25%**；100% 使用原版速度。

低速时会累计不足 1 像素的滚动量，连续小幅拖动仍能逐步滚动画布。此设置不改变手形工具的拖动画布速度。

## 可调的 Shift 选区移动步长

选中一个区域后，普通 **方向键** 每次移动 **1 个图像像素**，**Shift + 方向键** 默认每次移动 **4 个图像像素**，不依赖网格或 Tile 的宽高，也不随画布缩放改变。

在 **Edit → Preferences → Selection → Shift + Arrow move step** 中，可按 1 像素微调为 **2–64 像素**。**Alt + Shift + 方向键** 以相同步长移动选区边框。

两项偏好设置均在 Apply / OK 后保存。以上按键说明对应默认快捷键；自定义快捷键仍按其绑定的命令执行。

## 像素仿制图章

右侧工具栏提供独立的 **仿制图章** 工具，使用硬边像素笔刷。

1. 点击图章按钮，在目标位置按一下 **Y**，再点击画布设置取样点；也可使用顶部“取样”按钮。
2. 在目标位置按住左键拖动，复制源区域像素；再次按 Y 可重新取样，Esc 取消等待取样。
3. 取样位置以高对比十字显示，目标轮廓显示笔刷覆盖范围；这些标记不会写入图片或导出结果。
4. 顶部可调整笔刷形状、大小、不透明度，以及“取样图层 / 取样图层及以下 / 所有可见图层”。

按 Y 时的目标位置与所选源点确定相对偏移，后续绘制和跨笔画始终保留该偏移，直到重新取样；顶部按钮取样时以首次落笔确定目标点。每笔支持撤销/重做，并遵守目标选区。

取样图层由设置源点时的图层确定，可在普通图层与 **Tilemap 图层** 之间互相取样、绘制，也可写入空的可编辑图层。每笔使用新的源快照，避免同笔读取刚写入的像素。透明源像素和源画布外的像素会跳过。

Tilemap 上的图章按像素笔刷复制，保留 Tilemap 结构和 Tile 翻转效果。未开启专注格子时，写回遵循当前 Tileset 编辑模式：**Manual** 修改共享 Tile，所有引用它的位置同步变化；**Auto / Stack** 按原生规则匹配或生成 Tile。Manual 不会在空 Tile 中创建新内容。

开启 **专注格子** 后，Tilemap 图章可以从格外取样，只修改专注格与当前选区的交集。此时 Manual 的图章笔画会自动使用独立 Tile，避免影响格外共享同一 Tile 的内容；颜色栏设置不变。

支持 RGB、灰度和索引色；100% 不透明度下通常直接复制索引，背景保留索引写入透明层时映射为不透明颜色。不提供软边硬度、独立流量、镜像、笔刷动态、源旋转缩放或跨文档取样，不支持参考层取样和绘制。

默认单独 Y 用于取样，Cmd/Ctrl+Y 的重做和 Space+Y 的笔刷翻转仍保留；快捷键可自行调整。

## 专注格子

顶部 **专注格子** 挂锁按钮用于限制编辑范围。点击后，在画布上选择一个网格单元，绿色边框标出当前专注格，只能在这个格子内编辑；再次点击退出专注。

- 普通像素层和 Tilemap 层均支持铅笔、橡皮、填充、形状、图章等绘制，只写入专注格与当前选区的交集。
- 专注期间 Tilemap 绘图使用像素笔刷，即使颜色栏处于整 Tile 模式。Manual 的本次绘图临时使用 Auto 写回独立 Tile，保护格外共享引用；退出专注后沿用原来的模式。
- CE GUI / 双网格工具生成的 **Tile 优化** 工程保留原有 Index 关联：专注只限制落笔范围，同 Index 的其它格子仍同步更新，供外部程序正常刷新回读。
- 可以用 M 在格外选择纹理并复制/剪切，再移动或粘贴到格内；浮动选区保留完整纹理，落定时只写入锁定格内的目标像素。
- 锁定状态随当前文档保留，切换工具或图层不会解除；隐藏网格会解除锁定，更改网格尺寸或原点后需重新选格。
- 关闭文档或返回空工作区时，工具栏会解除该文档的网格设置订阅，避免退出清理访问已释放的设置。
- 专注状态不写入工程文件。参考层及整层移动仍不支持；Tilemap 浮动选区移动不属于普通像素层的写入裁剪管线。

## 静态图层界面

界面保留图层选择、显隐、锁定、分组和排序，隐藏帧网格、帧标签、播放、洋葱皮、帧菜单及状态栏帧操作。图层面板按钮控制面板显示，动画命令的快捷键和界面分发也已停用。

本 App 不提供帧动画编辑工作流。上游动画实现与文件格式代码仍保留，Lua / 旧扩展 API 未整体删除，但不作为本 App 的动画编辑能力提供或验证。需要动画编辑时请使用官方 Aseprite。

## 像素界面字体与独立字号

界面使用 **Fusion Pixel**，支持中文像素字体。**Preferences → General → Font Size** 可在 **75%–200%** 之间独立调整字号，默认 100%。

调整只影响界面文字，不改变画布内容、文字工具字号、图标或屏幕 / UI 缩放设置。

## 自定义工具栏与 macOS 品牌

原生 **OldKing Custom Toolbar** 可通过固定按钮调用已安装 Lua 扩展的命令；按钮顺序、命令与图标集中配置，使用原生工具栏的鼠标、弹出菜单和提示交互。

macOS 应用名为 **Aseprite Plus**，使用独立图标与 bundle identifier `studio.oldking.aseprite-plus`，并提供 `.ase` / `.aseprite` 文档和 `.aseprite-extension` 扩展图标。英文界面的 Crop / Trim 文案经过微调。

本机更新固定覆盖 `/Applications/Aseprite Plus.app`，不保留旧 App 备份。构建产物放在 `macos.noindex` 目录，安装器清理本项目旧备份和旧构建副本，并只向系统登记正式安装位置，避免搜索时出现多个版本。
